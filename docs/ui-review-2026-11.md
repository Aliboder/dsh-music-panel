# UI / 交互审计（2026-11-11）

范围：`dsh-music-panel` 的 Web 端（列表、选择、播放页、设置、对话框、在线、缓存）。
方法：读源码 + harness 实测 + 真实 DSH 截图（浅/深色）；不评估 Host 扫描与转码逻辑。

## 已在本轮修复（0.18.2）

| 问题 | 现象 | 处理 |
|---|---|---|
| Esc 双关闭 | 宿主 `Modal` 自己处理 Esc 后，面板的全局 Esc 还会再 `popLayer()`，可能把下层对话框也关掉 | 全局 Esc 检测到 `.mp-root` 之外的 `aria-modal` 对话框时直接返回，交给宿主关闭 |
| 区域选择无法退出 | 点「区域选择」后只能再点一次，没有 Esc/取消 | 全局 Esc 先 `cancelRangePick()` |
| 播放页 Aa 浮层不关 | 点外部/按 Esc 浮层仍在，遮挡歌词 | 加 `pointerdown` 外部关闭 + Escape |
| 单曲循环误高亮 | 播放模式胶囊在 `loop === 'one'` 时仍高亮「列表循环」 | 单曲循环时三种胶囊都不高亮，由播放条控制 |
| 标签保存后播放不恢复 | 保存前 `player.suspend()`，成功后没有恢复 | 保存成功/失败都尝试恢复原播放状态（用户已手动恢复则不重复 toggle） |

## P0：稳定性 / 可访问性

### 1. 列表和网格的 Tab 顺序失控

- 列表：`TrackRow` 每行 `tabIndex: 0`。实测 9 首歌 → 9 个 Tab 停靠点；真实库 268 首就是 **268 个**。
- 后果：键盘用户 Tab 要穿过整个列表。
- 建议：roving tabindex（只有焦点行/卡 `0`，其余 `-1`）+ ArrowUp/Down/Home/End 移动焦点；Enter 播放，Space 选择。这是最值得做的一项。

### 2. 宿主组件适配层是「全有或全无」

- 现在任一宿主组件 render 抛错，会被面板错误边界吞掉并显示空白（不是回退）。
- 建议：给 `KitModal / Switch / KitPill / Menu` 各包一层小型错误边界，失败时渲染对应本地 fallback；或者至少把 `Tooltip` 换成可选包装，减少单点故障面。

## P1：交互成熟度

### 3. 选择模式让工具栏换行 / 内容跳动

- `.mp-toolbar` 是 `flex-wrap: wrap`，`min-height: 34px`；进入选择模式后追加「已选 N 首 / 全选 / 取消全选 / 完成 / 播放选中 / 收藏 / 添加 / 批量编辑 / 删除」。
- 1322px 宽实测一行 44px；窗口再窄就会换行，列表整体下移。
- 建议：选择操作放进**固定高度的第二行**或浮层操作条，工具栏本体不增高；或在窄屏折叠为「更多」菜单。

### 5. 搜索每次按键都全量过滤

- `LocalContent` 在 render 中 `filterTracks(base, ui.query)`，没有 debounce / deferred。
- 目前 268 首无感；上万首时输入会卡。
- 建议：`useDeferredValue` 或 120–200ms debounce。

### 6. 添加音乐文件夹只有文本框

- 设置 → 音乐库的根目录靠手输路径，没有目录选择器；用户很容易输错。
- 建议：优先用宿主提供的目录选择能力；拿不到就至少做路径存在性校验与「浏览」提示。

### 7. 设置面板窄屏两栏拥挤

- `.mp-sheet` 固定 `grid-template-columns: 180px 1fr`，宽度 `min(760px, 100%)`，没有断点折叠。
- 窄窗口下正文只剩不到 400px。
- 建议：<720px 时把左侧导航变成顶部分段控件（`SegmentedTabs` 或横向 tabs）。

### 8. 缓存页只能看，不能清

- 设置 → 缓存只有统计和提示；Host 有 `/online/cache/remove`（单曲），`online-cache` 也导出了 `clear()`，但没有 clear-all 路由，也没有 UI 入口。
- 建议：加 `POST /online/cache/clear` + 设置页「清空缓存」，以及缓存列表的单条删除。

### 9. 批量编辑 / 回收站恢复是串行 + 全量重扫

- `batchEditTags` 对每首 `GET tags` + `PUT tags` 串行；没有进度、不能取消。
- 回收站恢复、批量保存、删除后都 `loadLibrary(true)` 全量重扫。
- 建议：批量操作给出「n / total」进度条与取消；rescan 用增量或防抖合并。

### 10. 在线缓存与登录的边界态

- 登录二维码没有「刷新二维码」按钮，过期后只能关掉重开。
- 在线歌曲缓存没有「不再缓存」开关（设置里只有清理）——如果产品需要，可加。

## P2：一致性 / 文案

| 项 | 现状 | 建议 |
|---|---|---|
| 播放模式两套入口 | 顶栏胶囊与播放条 shuffle/repeat 都能改，语义不完全一致 | 胶囊作为唯一「模式」入口，播放条只保留上一首/播放/下一首 |
| 选择菜单 vs 工具栏 | 菜单「全部取消」会退出选择模式，工具栏「取消全选」只清空 | 统一为「取消全选」清空、退出用「完成」；或菜单改成「退出多选」 |
| 标签保存/批量保存的 toast | 只报成功数量，失败数量被吞 | `已保存 N 首，失败 M 首` |
| 在线页空态 | 只有文字提示 | 可加宿主 EmptyState / 插画（宿主有 `PluginArtwork*`） |

## 已经比较稳的部分

- 主题：token 化 + `theme.test.mjs` 守卫，浅/深色都验证过。
- 对话框/菜单/Toast/Switch/Pill：宿主组件，焦点陷阱、Escape、外部点击都由宿主处理。
- 选择模型：`selectTrackIn` 单击替换、Ctrl/勾选追加、双击不破坏选择，边界处理过。
- 错误处理：路由统一 `fail()`，对话框有 loading/error 态，测试覆盖路由与渲染。
- 卸载清理：`ctx.effect` + Audio/EventSource/计时器清理，避免重复挂载泄漏。
