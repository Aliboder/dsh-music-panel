# 08 验收清单

提交前逐条勾选；任何一条不满足都视为未完成。

## A. 结构

```text
[ ] 只有 host-ui.js 直接 require 宿主包
[ ] 业务代码通过适配层使用控件，没有直接渲染宿主导出
[ ] 适配层函数名唯一，没有与业务本地组件重名
[ ] CSS 前缀统一，仓库内 grep 旧前缀为 0
```

## B. 适配层

```text
[ ] 宿主可用时渲染宿主组件（native 路径实测）
[ ] 宿主不可用时渲染 fallback（临时让 hostComponent 返回 null 实测）
[ ] 两条路径 props 一致，onChange 语义一致
[ ] role / aria-* / tabIndex / 键盘行为一致
[ ] 几何一致（对照 06 与 参考/）
[ ] 颜色只用 token，无写死十六进制
```

## C. 测试页

```text
[ ] 每个控件至少一个默认态 + 一个非默认态
[ ] 每个用例有 adapter 名与可复制的 code
[ ] 顶部显示 native / fallback 实际状态与使用说明
[ ] 代码块里的 props 与适配层一致
[ ] zh / en 文案键齐全
```

## D. 主题

```text
[ ] 浅色主题正常
[ ] 深色主题正常
[ ] 深色岛单独验证（开关 / 分段 / 输入框 / 页签）
[ ] hover 只在 @media (hover: hover)
[ ] focus-visible 可见，offset 正确
```

## E. 可访问性

```text
[ ] 图标按钮有 aria-label
[ ] 开关有 role=switch + aria-checked
[ ] 分段/页签有 aria-selected 与 aria-controls
[ ] 弹窗有 role=dialog + 初始焦点 + Escape
[ ] 输入有 label 或 aria-label
[ ] 同页无重复 DOM id
```

## F. 交付

```text
[ ] 构建通过（项目自己的 build 命令）
[ ] 测试通过（项目自己的 test 命令）
[ ] 客户端/服务端产物已重新生成（如有）
[ ] 文档同步（本规范 / 测试页 / CHANGELOG）
[ ] 已安装到 profile 并完全重启验证（如项目有该流程）
```
