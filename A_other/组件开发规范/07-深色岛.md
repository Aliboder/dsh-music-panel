# 07 深色岛

## 1. 什么是深色岛

面板在**浅色主题下仍然是深色**（例如浮层、沉浸式工具面板）。宿主组件读的是全局 token，在浅色主题下会取到浅色值，于是出现：

- 开关：白色轨道 + 白色滑块（分不清开关）；
- 分段：页签外框变成浅灰；
- 输入框：白底浅字。

解决方式：在岛的根元素上把相关 token 固定成**深色主题的同一组静态来源**。

## 2. 规则

1. 只在岛根固定，不在每个控件上固定；
2. 用 `--dsw-static-*` 静态来源，不要手写十六进制近似色；
3. 只固定宿主控件会读到的 token，固定越多，维护面越大；
4. 固定后必须切到浅色主题验证一遍；
5. 岛内的本地样式也优先使用这些 token，保持同一套色阶。

## 3. 推荐固定清单

```css
.ui-island{
  /* 文字 */
  --dsw-alias-label-primary: var(--dsw-static-neutral-bluish-50);
  --dsw-alias-label-secondary: var(--dsw-static-neutral-bluish-300);
  --dsw-alias-label-tertiary: var(--dsw-static-neutral-bluish-400);
  --dsw-alias-label-primary-foreground: var(--dsw-static-neutral-bluish-1000);

  /* 表面与描边 */
  --dsw-alias-bg-module-platform: var(--dsw-static-neutral-bluish-800);
  --dsw-alias-border-l3: rgba(255, 255, 255, .16);

  /* 交互与品牌 */
  --dsw-alias-brand-primary: var(--dsw-static-neutral-bluish-50);
  --dsw-alias-switch-thumb: var(--dsw-static-neutral-bluish-400);
  --dsw-alias-interactive-bg-hover: rgba(255, 255, 255, .08);
  --dsw-alias-interactive-bg-active: rgba(255, 255, 255, .14);

  /* 主按钮 */
  --dsw-alias-button-primary-fill: #4f8cff;
  --dsw-alias-button-primary-hover: #6aa0ff;
  --dsw-alias-state-business-primary: #4f8cff;
}
```

说明：

- `label-primary-foreground` 必须固定：开关开启态的滑块读它，不固定会变成浅色主题的白色 → 白底白滑块；
- `brand-primary` 固定成 bluish-50：开启轨道接近白，与深色滑块形成对比；
- `switch-thumb` 固定成 bluish-400：关态滑块保持亮灰，两种主题下都可见；
- `bg-module-platform` 固定成 bluish-800：页签外框不会在浅色主题下变浅；
- 如果岛内使用输入框，再补 `bg-layer-1`、`border-l4` 的深色值。

## 4. 验证方法

```text
[ ] 切到浅色主题，打开深色岛
[ ] 开关：开态白轨道 + 深滑块；关态半透明轨道 + 灰滑块
[ ] 分段控件：指示块可见，未选项文字可读
[ ] 分段页签：外框深色，选中项字重正确
[ ] 输入框：深底浅字，占位符可见
[ ] 所有 host 控件都至少被一个岛根 token 覆盖
```

## 5. 常见错误

| 错误 | 现象 | 修正 |
|---|---|---|
| 只固定 `brand-primary` | 滑块仍是白色 | 同时固定 `label-primary-foreground` 与 `switch-thumb` |
| 手写 `#f4f4f5` 当轨道 | 与官方开关差一点灰 | 用 `--dsw-static-neutral-bluish-50` |
| 在控件上固定 | 每个控件都要重复，漏一个就翻车 | 只在岛根固定 |
| 固定所有 token | 维护面过大 | 只固定宿主会读的 |
