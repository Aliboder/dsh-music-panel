# 轻提示与杂项

## 轻提示（Toast）

宿主有 `Toast` **组件**（`{ text, icon, tone, anchor, holdMs, actions, onDone }`），但插件通常需要**服务式**提示（任意位置调用、自动排队）。

两种形态不要混用：

| 形态 | 适用 | 不适用 |
|---|---|---|
| 组件式 Toast | 挂在某个锚点旁边的一条消息 | 全局操作反馈 |
| 服务式 `showToast(text)` | 保存成功、复制成功、失败提示 | 需要锚点定位的消息 |

服务式提示的要求：

```js
function showToast(text) {
  // 1. 容器 aria-live="polite"，role="status"
  // 2. 同时最多 3 条，超出丢弃最旧
  // 3. 默认 2.4s 自动消失；错误提示 4s
  // 4. 不阻塞焦点、不抢键盘
  // 5. 文案由调用方传入，组件不自造
}
```

fallback 样式：

```css
.ui-toast{position:fixed;left:50%;bottom:24px;transform:translateX(-50%);z-index:100;
  display:flex;flex-direction:column;gap:8px;pointer-events:none}
.ui-toast-item{pointer-events:auto;padding:8px 12px;border-radius:var(--dsw-radius-md);
  background:var(--dsw-alias-bg-layer-1);color:var(--dsw-alias-label-primary);
  box-shadow:var(--dsw-elevation-prominent);font-size:13px;line-height:20px}
```

## Range（滑杆）

DSH 没有 Range 原语，官方视觉是原生 `input[type=range]` + token：

```js
h('input', {
  type: 'range',
  className: 'ui-range',
  min: 0,
  max: 100,
  value: value,
  'aria-label': label,
  onChange: function (event) { onChange(Number(event.target.value)) },
})
```

```css
.ui-range{-webkit-appearance:none;appearance:none;width:100%;height:20px;background:transparent;cursor:pointer}
.ui-range::-webkit-slider-runnable-track{height:4px;border-radius:999px;
  background:var(--dsw-alias-border-l3)}
.ui-range::-webkit-slider-thumb{-webkit-appearance:none;width:14px;height:14px;margin-top:-5px;
  border:0;border-radius:50%;background:var(--dsw-alias-brand-primary)}
.ui-range:focus-visible{outline:var(--dsw-focus-ring-width) solid var(--dsw-focus-ring-color);
  outline-offset:4px;border-radius:999px}
```

## Spinner 与 Empty

```js
function Spinner() {
  return h('span', { className: 'ui-spinner', 'aria-hidden': 'true' })
}

function Empty(props) {
  return h('div', { className: 'ui-empty' },
    icon(props.icon || 'note', 26),
    h('strong', null, props.title),
    props.hint ? h('span', null, props.hint) : null)
}
```

```css
.ui-spinner{display:inline-block;width:16px;height:16px;border-radius:50%;
  border:2px solid var(--dsw-alias-border-l3);
  border-top-color:var(--dsw-alias-label-primary);animation:ui-spin .8s linear infinite}
@keyframes ui-spin{to{transform:rotate(360deg)}}
.ui-empty{display:flex;flex-direction:column;align-items:center;justify-content:center;
  gap:6px;padding:24px;color:var(--dsw-alias-label-tertiary);font-size:12px}
```

## SetRow（设置行骨架）

```js
function SetRow(props) {
  return h('div', { className: 'ui-set-row' },
    h('div', { className: 'ui-set-label' }, props.label,
      props.desc ? h('span', { className: 'ui-set-desc' }, props.desc) : null),
    h('div', { className: 'ui-set-control' }, props.children))
}
```

```css
.ui-set-row{display:flex;align-items:center;gap:12px;min-height:44px;padding:8px 0}
.ui-set-label{display:flex;flex-direction:column;gap:2px;flex:1;min-width:0;
  font-size:13px;line-height:20px;color:var(--dsw-alias-label-primary)}
.ui-set-desc{font-size:12px;line-height:18px;color:var(--dsw-alias-label-tertiary)}
.ui-set-control{display:flex;align-items:center;gap:8px;flex:none}
```

## 危险操作按钮

不要新造 variant；用工具类叠加错误色：

```css
.ui-danger-btn{color:var(--dsw-alias-state-error-primary);
  box-shadow:inset 0 0 0 .5px color-mix(in srgb,var(--dsw-alias-state-error-primary) 38%,transparent)}
```

## 坑

- 轻提示不要用 `alert()`；也不要放在会随页面卸载的容器里。
- Range 的 `onChange` 每个浏览器事件都触发；需要节流时在调用方做，不要改适配层语义。
- 空状态必须有文案；只有图标或只有骨架屏不算完成。
- 设置行右侧控件宽度由内容决定，不要给 `SetRow` 设固定高度。
