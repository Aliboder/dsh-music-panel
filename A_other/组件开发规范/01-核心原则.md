# 01 核心原则

以下七条是判定标准，不是口号。任何一条不满足，控件就不算完成。

## 1. 宿主优先

DSH 提供 `@deepseek-ai/dsh-client-ui-primitives` 时，必须渲染宿主组件；只有宿主不可用（测试环境、旧版本、包缺失）才渲染 fallback。

```text
hostComponent('Button') !== null  →  宿主 Button
hostComponent('Button') === null  →  本地等价物
```

不要因为「fallback 更好看」或「宿主属性不熟」就绕过宿主。

## 2. fallback 等价

「等价」不是看起来像，而是五件事都对得上：

| 维度 | 要求 |
|---|---|
| props | 调用方只写一种调用，适配层负责翻译 |
| DOM | 标签、`role`、`aria-*`、键盘行为一致 |
| 几何 | 高度、内衬、圆角、字号、指示块动画一致 |
| 交互 | hover / active / disabled / focus-visible 一致 |
| 颜色 | 使用同一组 token，不写死十六进制 |

判定方法：把 `hostComponent` 临时改成返回 `null`，界面应只剩「渲染实现不同」，不该出现「布局或行为不同」。

## 3. 测试页是唯一标准

每个控件必须先出现在组件测试页，并同时给出适配层名与可复制的调用代码。业务里只允许出现测试页验证过的写法。

新增控件或新增变体的顺序：**测试页立用例 → 业务使用**，不允许反过来。

## 4. token 优先

颜色、圆角、阴影、焦点环一律用 token：

```css
color: var(--dsw-alias-label-primary);
border-radius: var(--dsw-radius-md);
box-shadow: var(--dsw-elevation-soft);
```

禁止：`#fff`、`rgb(255 255 255)`、`rgba(0,0,0,.2)` 这类写死值（`color-mix` 里引用 token 除外）。

## 5. 深色岛必须固定 token

如果面板在浅色主题下仍是深色，宿主控件会读到浅色 token（例如开关变成白底白滑块）。必须在岛根把相关 token 固定成深色主题的同一组静态来源，不能用近似色。见 `07-深色岛.md`。

## 6. 表面与文字同源

浮层的背景和文字必须来自**同一个主题作用域**。表面用宿主 `bg-*` token、文字却从深色页面 `color: inherit` 继承硬编码白色，是浅色主题下最常见的「白底白字」。

```text
禁止：background: var(--dsw-alias-bg-layer-1);  /* 跟宿主主题 */
      color: inherit;                           /* 从深色页面继承白色 */

要求：background: var(--dsw-alias-bg-layer-1);
      color: var(--dsw-alias-label-primary);
```

- `label-primary` 背景必须配 `label-primary-foreground`，不能配 `bg-base`；
- `bg-*` 是表面 token，永远不要作为 `color`；
- 每个浮层/弹层/卡片在根节点显式声明 `color`，不要依赖祖先；
- 深色页面里的子浮层，如果要跟随 DSH 主题，就不要做深色岛；要始终深色，才在岛根固定整组 token；
- 外层 token 化不代表内部完成：复用自深色区域的子组件要重新过一遍 token。

## 7. 唯一加载入口

整个插件只允许一个文件 `require('@deepseek-ai/dsh-client-ui-primitives')`（`host-ui.js`）。业务代码一律通过 `hostComponent(name)` 取组件，方便升级、降级与测试。

## 反例 → 正例

| 反例 | 正例 |
|---|---|
| 业务里直接 `require` 宿主包 | `hostComponent('Switch')` |
| 自绘开关，只把颜色调得像 | 适配层 + fallback 同几何（36×20，滑块 16） |
| 分段控件用固定默认 id | 每个实例自增 id，避免重复 `aria-controls` |
| 深色卡片里直接用宿主 Switch | 先在岛根固定 `--dsw-alias-*` |
| 表面用宿主 token，文字 `color: inherit` | 浮层根节点显式 `color: var(--dsw-alias-label-primary)` |
| `color: var(--dsw-alias-bg-base)` | 改用与背景配对的 `label-primary-foreground` |
| 写死 `#f4f4f5` | `var(--dsw-alias-label-primary)` |
| 先写业务，后补测试页 | 先在测试页立用例 |

## 完成定义

一个控件只有同时满足以下条件才算完成：

```text
[ ] 测试页有用例（adapter + code + 实际控件）
[ ] native 与 fallback 都跑过
[ ] 浅色 / 深色（含深色岛）都看过
[ ] 浮层放回真实祖先（深色页面/卡片/弹窗）切过两套主题
[ ] 表面与文字来自同一套 token，不靠 color: inherit 穿透主题作用域
[ ] 键盘与焦点可见
[ ] 几何与宿主一致（对照 06 与 参考/）
[ ] 08-验收清单.md 全过
```
