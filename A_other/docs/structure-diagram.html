验收标准

每一步只允许路径/import/manifest 变化，逻辑零改动。

  • ✓108 tests 全绿
  • ✓client.js 归一化 SHA-256 不变
  • ✓Folia bundle 哈希不变
  • ✓浅 / 深色截图一致
  • ✓pack / 安装冒烟通过

不做的事

  • 不重写 Client / Host，不新增/删除功能
  • 不换 UI、交互、样式、文案
  • 不把 JS 重写成 TS
  • 不做数据迁移/兼容

搬迁原则

  • 一次只搬一个领域组，一个 commit
  • 只改路径 / import / manifest / 测试引用
  • 遇到循环依赖先记录，不在搬家 commit 里重构
  • 每步可单独回退
