# Folia 移植差距清单

审计对象：`dsh-music-panel` 当前实现 vs `A_other/upstream/folia-major-main`。

结论：音频、歌词管线、歌词样式、背景渲染已经大量源码级移植；**播放页外壳、面板页签、队列、播放控制栏、样式运行参数、转场和性能策略仍未对齐或未移植**。

## 1. 已经对齐的部分

| 内容 | 现状 |
|---|---|
| 音频图、EQ、音量平衡、自动混音信号 | `src/audio/entry.ts` 直接 import Folia 源码 |
| 歌词解析、断词、时间线 | `lyrics.bundle.js` 由 Folia 源码编译 |
| 歌词样式 | 14 个 Folia renderer 源码（含 `classic`）已接入 |
| 歌词背景 | 6 种 Folia 背景 renderer 源码 |
| 时计（pendolo） | 单独的 Folia 源码 bundle |
| 封面主题生成 | Folia 的 `builtinTheme` / `baseThemes` |

## 2. P0：播放页外壳 / 面板还没对齐

| 差距 | Folia | 当前插件 |
|---|---|---|
| 面板基座 | `PanelShell` + `SongHeader` + `TabDock` + `PanelHandle` | `player-sheet.js` 的适配实现 |
| 页签 | 封面 / 本地或在线歌词 / 控制器 / 队列 / 账户，随歌曲类型变化 | 固定 4 个：歌曲 / 歌词 / 音频 / 外观 |
| 队列 | 面板里的独立页签 | 独立弹层，不在面板页签内 |
| 手柄 | `PanelHandle`：拖动、命令面板、悬停引导 | 简单圆形按钮 + 自动隐藏 |
| 控制栏 | Folia 的播放控制栏 / 进度胶囊 | `NowPlayingCapsule` 自定义实现 |
| 自动隐藏设置 | `autoHidePlayerChrome` 等设置 | 固定 3 秒自动隐藏，无对应设置 |

这一块是用户最直接能感知的“外壳不一致”。

## 3. P1：队列行为还没对齐

Folia `QueueTab` 有，而当前队列没有：

- 虚拟列表（`react-window`），只渲染可见行；
- 列表底部渐隐；
- 行内「下一首播放 / 移到末尾 / 删除」三个动作；
- 队列保存为本地歌单；
- 打开队列海报墙 / 速记簿队列；
- 随 `--pn-tab-room` 自适应高度。

当前 `mpv3-queue` 是自定义列表，支持拖拽排序和删除，但没有上述行为和新的页签结构。

## 4. P1：样式运行参数和转场缺失

| 差距 | 影响 |
|---|---|
| 每个样式的 tuning / 设置面板未移植 | 只能使用默认参数，用户无法调 Folia 的字距、旋转、强度等 |
| 样式切换 soft focus / background transition 未移植 | 换样式时直接切换，没有 Folia 的过渡 |
| 共享字幕 / Harmony overlay 未移植 | 部分样式缺少 Folia 的叠加层行为 |
| 全局渲染质量档位、帧率上限、预 warm 未移植 | 性能和掉帧行为与 Folia 不同 |
| `nebbia` 笔画数据未移植 | 缺少原作笔画，回退到字体骨架 |
| Smart beat / 鼓 stem 关闭 | Folia 的鼓点/齿轮效果不会出现 |

## 5. P2：背景与主题

- 背景**渲染器**已移植，但背景设置卡片和 tuning 没有：Paper shader、Monet 布局、Nomand 效果、URL 列表都只暴露了「模式 + 一个 URL」。
- `monet` 背景在 Folia 用 Worker；插件改成主线程 `OffscreenCanvas`，画面相同但主线程开销不同。
- Folia 的 AI 主题、自定义主题编辑器、app 级壁纸 / 透明页面模式未移植。

## 6. P2：样式数量仍不全

Folia 有 17 个内建模式，当前插件注册的是：

```text
classic, still, tilt, partita, claddagh, cadenza, fume, monet,
lumiere, sonnet, tempera, hanabi, nebbia, diorama + pendolo
```

当前样式目录已补齐 cappella 与 machi；machi 的设置面板仍使用 stub，tuning UI 未接入。

## 7. P3：设置与在线层

- Folia 的设置窗口、每样式设置卡、账户页签没有逐文件移植；当前是 DSH 设置页 + 自定义账户界面。
- 在线音乐层是插件自己的 provider / Host 架构，不是 Folia `omni` 的源码级移植；搜索、榜单、登录、缓存等行为需要单独审计。
- 播放队列、播放状态机、自动混音编排是插件自己的实现；只有底层音频图直接来自 Folia。

## 8. 审计边界

以下项目插件本来就不需要和独立客户端一致，属于适配层：

```text
DSH 宿主生命周期、窗口控制
DSH 设置入口和宿主控件
插件数据目录、Host HTTP 接口
插件独有的在线平台 / 本地库
```

这些可以不同，但必须写在适配层，不要混进 Folia 业务逻辑。

## 9. 建议顺序

```text
1. UnifiedPanel 外壳：PanelShell + SongHeader + TabDock + PanelHandle（DSH 皮肤）
2. 队列页签：QueueTab 行为 + 虚拟列表 + 行内动作
3. 播放控制栏和自动隐藏设置
4. 每样式 tuning / 设置面板
5. 样式转场、共享 overlay、渲染质量 / 预 warm
6. cappella / machi
7. 背景设置卡、Monet Worker、主题编辑器
8. 在线层与播放状态机的逐项行为审计
```

第 1 步是后续所有面板页签的基座，先做它；否则队列、控制器、账户每加一个页签都会再次重写外壳。
