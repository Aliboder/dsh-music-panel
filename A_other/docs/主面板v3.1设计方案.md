## 1. 第 2 个问题：平台到底有哪些

### 1.1 代码里的真实情况

0.37.2 的在线平台不是固定 7 个：

- 内置注册表只有 4 个在线平台：<code>netease</code>、<code>qq</code>、<code>kugouLite</code>、<code>navidrome</code>（<code>src/host/providers/index.js</code> 的 <code>PROVIDERS</code>，<code>src/host/providers/sources/index.js</code> 的 <code>ONLINE_SPECS</code>）。
- 波点（bodian）和汽水（qishui）是可选包：安装并注册成功才出现；缺包时 Host 直接不注册，不会报错（<code>registerBodianSource</code> / <code>registerQishuiSource</code>）。
- 浏览器端不是读一个写死的数组：<code>availableSources()</code> 先放本地和内置顺序，再把 <code>/online/providers</code> 返回的、已注册的平台追加进来（<code>src/client/components/common/ui.js</code>）。
- 每个平台能做什么，来自它自己声明的 <code>capabilities</code>（<code>src/host/services/core/contract.js</code>），不是面板猜的。

所以：你截图里有 7 个，是因为你的实例装了波点和汽水的可选包；干净安装可能只有 5 个。新面板必须按运行时返回画，不能把 7 个写死。

### 1.2 新面板的规则

1. 来源菜单 = 本地 + <code>/online/providers</code> 返回的已注册平台；没注册的不画。
2. 平台显示名、登录方式、能力、可用状态都从返回数据取；已知平台用现有中文标签，未知平台用 <code>displayName</code>。
3. Navidrome 已注册但未配置：显示“未配置”，点击引导去设置，不打开空页。
4. 可选包未安装：来源菜单里不出现；只在「设置 → 在线」里管理（设置页不动）。
5. 来源菜单底部加「管理来源」，打开现有设置 → 在线；不新增设置页。
6. 能力表只用于文档和测试快照；UI 的真相是运行时 <code>capabilities</code>。

## 2. 第 1 个问题：队列改为浮窗

### 2.1 形态

播放条右侧的队列按钮，点开后是一个贴着播放条右上方浮出的面板：

~~~text
                                      ┌──────────────────────────┐
                                      │ 队列  12 首 · 顺序  清空 定位 关闭 │
                                      ├──────────────────────────┤
                                      │ 正在播放                  │
                                      │ ▣ 晴天 / 周杰伦      4:29 │
                                      ├──────────────────────────┤
                                      │ 接下来播放                │
                                      │ ▣ 夜曲 / 周杰伦      3:48 │
                                      │ ▣ Lemon / 米津玄師   4:16 │
                                      │ …                        │
                                      └──────────────────────────┘
┌────────────────────────────────────────────────────────────────┐
│ 封面 晴天 / 周杰伦 ♥    ⟲  ⏮  ▶  ⏭  ⟳      [队列] [音量] [展开] │
└────────────────────────────────────────────────────────────────┘
~~~

- 宽度 340，最大高度 <code>min(560px, 62vh)</code>；圆角 16；层级阴影；不遮全屏、不加遮罩。
- 定位：贴着播放条右上方，距离右边 14、距离播放条 12；窄窗口变成左右各留 8 的全宽浮窗。
- 打开/关闭：点队列按钮、Esc、点面板外、点关闭按钮；关闭后焦点回到队列按钮。
- 不占用内容区宽度：内容列表永远不被挤窄，也不因为开队列隐藏专辑列。
- 播放页里的队列保持原样，不改结构。

### 2.2 内容

- 头部：队列、总数量、顺序/随机、清空、定位当前、关闭。
- 「正在播放」：当前曲一行。
- 「接下来播放」：剩余曲目；当前行高亮；点行播放；悬停出现移除按钮。
- 清空：只清空“接下来播放”，保留当前曲。
- 队列为空：图标 + “队列是空的” + 去歌曲页。
- 键盘：打开后焦点进面板；↑/↓ 走行；Enter 播放；Esc 关闭。

### 2.3 为什么不是第三列

- 成熟播放器（QQ 音乐/网易云桌面）的队列是浮层或抽屉，不是永久第三列。
- DSH 主区域宽度会随宿主侧栏变化；第三列在窄窗口只能隐藏，体验断裂。
- 浮窗不改变内容布局，打开/关闭无跳动。

- 返回记录只存页面和参数，不写浏览器 URL；返回恢复滚动位置。
- 从搜索进入详情，返回回到搜索结果（搜索词保留）；从详情进入详情，逐层返回。

## 4. 第 4 个问题：组件是否对齐 DSH

### 4.1 结论

- 最终实现是对齐 DSH 的：面板里不新画按钮、输入框、开关、分段、菜单、对话框；全部走宿主组件或本仓原语。
- demo 不是最终外观：单文件 HTML 不能加载宿主的 React 组件，所以 demo 用近似的 HTML/CSS 表达结构；颜色已经换成 DSH 官方 token 值，但控件仍是仿的。
- 真实实现里，demo 的 <code>.btn</code>、<code>.ibtn</code>、<code>.tab</code>、<code>.menu</code> 会分别换成 <code>Button</code>、<code>IconButton</code>、<code>KitSegmentedTabs</code>、<code>HeadMenu</code>/宿主 <code>Menu</code>。

### 4.2 组件对照

| 位置 | 最终用什么 | demo 里是什么 |
|---|---|---|
| 普通按钮 | <code>Button</code>（宿主 Button，variant/size） | <code>.btn</code> 仿制 |
| 图标按钮 | <code>IconButton</code>（宿主 Tooltip + 本地 fallback） | <code>.ibtn</code> 仿制 |
| 页面标签 | <code>KitSegmentedTabs</code>（sm 34） | <code>.tabs/.tab</code> 仿制 |
| 来源/排序/选择/账号菜单 | <code>HeadMenu</code> / 宿主 <code>Menu</code> | <code>.menu</code> 仿制 |
| 搜索框 | <code>KitInput</code>（宿主 Input） | <code>input.search</code> 仿制 |
| 开关（设置页） | <code>Switch</code> | 设置页不改 |
| 对话框（确认/标签/登录） | <code>KitModal</code> | demo 用 toast 代替 |
| 轻提示 | 宿主 Toast / <code>showToast</code> | <code>.toast</code> 仿制 |
| 空态 | <code>Empty</code> | <code>.empty</code> 仿制 |
| 封面 | <code>Cover</code> | 渐变 div 仿制 |
| 歌曲行/网格/详情头 | 一次性布局 + token | 一次性布局 + token |
| 队列浮窗 | 本仓复合容器（不是菜单） | <code>.queue</code> 仿制 |
| 播放条进度 | <code>SeekBar</code> 语义或带 range 的自定义进度 | 2px 进度线 |

## 5. 第 5 个问题：交互对齐成熟播放器

### 5.1 先说明一个冲突

你之前要求“单击选择”保持现状；主流播放器其实有两种：

- Spotify / Apple Music：单击行播放，复选框/多选用于选择。
- QQ 音乐 / 网易云 / 酷狗桌面版：单击行选中，双击播放，悬停出现播放按钮。

你常用的平台是后一组。因此本方案默认保留“单击选中”，但补上成熟播放器的三件事：悬停播放按钮、选择操作条、双击播放提示。这样既符合你之前的要求，也符合国内桌面播放器的习惯。

如果你更想要 Spotify 那种“单击就播”，只需要把行的单击动作从“选中”换成“播放”，并用复选框/右键选择；其余结构不变。

### 5.2 与成熟播放器对照

| 交互 | QQ/网易云桌面 | Spotify/Apple Music | 本方案 |
|---|---|---|---|
| 单击行 | 选中 | 播放 | 选中（保留你的要求） |
| 悬停播放按钮 | 有 | 有 | 有（封面上的播放/暂停） |
| 双击行 | 播放 | 播放 | 播放 |
| 多选 | Ctrl/右键/选择模式 | 复选框 | Ctrl/右键 + 选择操作条 |
| 队列 | 右侧浮层/抽屉 | 右侧栏 | 浮窗（回答 1） |
| 搜索 | 搜索页 | 搜索页 | 聚焦搜索框即进入搜索页 |
| 专辑页 | 大封面 + 播放全部 + 列表 | 同 | 同 |
| 艺人页 | 头像 + 热门 + 专辑 | 同 | 同 |
| 播放条 | 底栏 | 底栏 | 底栏 |
| 键盘 | 基础 | 完善 | 完善：方向键/Enter/Space/Esc// |

### 5.3 行交互

- 单击行：选中；再次单击唯一选中项取消；Ctrl/Cmd 加选/减选。
- 悬停封面：出现播放按钮；点它播放；当前行显示暂停/播放。
- 双击行：从该行开始播放当前列表。
- Enter：播放键盘焦点行。
- 右键：单曲菜单/多选菜单。
- 选择操作条：选择后替换视图栏（高度不变），显示已选数量、全选、播放、收藏、添加到歌单、批量编辑、删除、完成。
- 不新增假按钮：没有歌词、没有关注、没有下载；所有菜单项对应真实接口。
- 当前行和选中行：当前行左侧强调条 + EQ；选中行淡强调底 + 勾；两者同时存在可分。

### 5.4 右键菜单

单曲：播放、下一首播放、加入队列、收藏/取消收藏（能力允许时）、添加到歌单（能力允许时）、查看专辑/艺人、歌词匹配、标签编辑（本地）、删除（本地）。

多选：全选、取消选择、区域选择、完成、播放选中、收藏选中、添加到歌单、批量编辑（本地）、删除（本地）。

- 菜单贴指针，视口钳制；滚动/缩放/Esc 关闭。
- 能力不足的项：不显示或禁用并写明“该平台不支持”。

### 5.5 搜索

- 顶部搜索框是入口，不是“当前列表过滤器”。
- 点一下/聚焦搜索框 → 进入当前来源的搜索页；输入 250ms 防抖，回车立即。
- 结果按歌曲/专辑/艺人/歌单分组；在线平台只显示它支持的分组。
- Esc/清除 → 回到进入前的页面；返回记录保留搜索词。
- 「筛选当前列表」不放在顶部搜索框里；如果以后需要，用视图栏的漏斗按钮单独做，避免一个框两种含义。
- 这样和 QQ/网易云/Spotify 的“搜索页”心智一致。

### 5.6 队列

见第 2 节：浮窗、正在播放/接下来播放、清空、定位、移除、Esc/外部关闭。

### 5.7 播放条

- 左：封面 44、标题/艺人、喜欢、来源小标。
- 中：随机、上一首、播放/暂停 36、下一首、循环。
- 右：时间、睡眠胶囊、定位、队列、音量、展开。
- 顶边 2px 进度线（悬停 4px）；点击/拖动定位；缓冲进度；时间预览。
- 点封面/标题/空白打开播放页；按钮区域不触发。
- 空态、窄屏、播放失败与现在一致。
- 睡眠、音量、静音、随机/循环语义不变。

### 5.8 键盘

- <code>Space</code> 播放/暂停；<code>/</code> 聚焦搜索；<code>Ctrl/⌘ + ←/→</code> 上一首/下一首。
- ↑/↓ 在列表移动焦点；Home/End 首尾；Enter 播放。
- Esc 顺序：菜单 → 区域选择 → 选择 → 搜索 → 返回 → 队列 → 播放页。
- 菜单 Esc 关闭，焦点回入口；列表焦点环不被裁切。

## 9. 多平台（运行时能力）

### 9.1 页面生成

- 有 <code>songs</code> 才有整库歌曲；有 <code>albums</code> 才有专辑；有 <code>artists</code> 才有艺人；有 <code>userPlaylists</code> 才有歌单；有 <code>recent</code> 才有最近；本地才有文件夹/统计。
- 标签顺序：本地 <code>songs/albums/artists/folders/favorites/playlists/stats</code>；Navidrome <code>songs/albums/artists/recent/playlists</code>；中文平台 <code>recent/albums?/artists?/playlists?</code>。
- 平台未注册：不出现；平台已注册未配置：显示“未配置”，点击去设置。

- 页面级错误：原因 + 重试；操作错误：toast。

### 9.4 加平台

只加能力声明 + 接口；导航、页面、徽标自动长出来。面板不写 <code>if (平台 === ...)</code>。
