# 踩坑记录

一条一坑，格式：**原因会导致现象的问题**（每条 ≤100 字，含最短对策）。改代码/发布前先全文搜一遍。

---

## 1. Folia 用 React 19 的 ref prop，宿主 React 18 会导致背景不随音乐扭曲。

## 2. 背景/样式是独立 bundle，只重建 client.js 会导致画面仍是旧版。

## 3. 把 bands 归一化成 0..1 会导致背景鼓点完全不动。

## 4. analyser smoothing 设 0.82 会导致鼓点被抹圆、声音发钝。

## 5. 不给 audioBands.spectrum 会导致莫奈频谱退化成五段插值。

## 6. 误以为暂停应完全冻结会导致观感与 Folia 不一致。

## 7. 以为所有背景都吃音频会导致误判音频分析坏掉。

## 8. 旧 ambient 回响层残留会导致刷新后仍是旧背景。

## 9. 保留「暂无歌词」占位会导致纯音乐画面被文案挡住。

## 10. 浅色主题卡片没做深色岛 token 会导致白底白字。

## 11. 主题守卫不扫新 UI 与内联圆角会导致违规样式漏过测试。

## 12. 只测 native 宿主组件会导致 fallback 控件缺失或错位。

## 13. profile 装的是 tarball 副本而非工作区 link 会导致改源码不生效。

## 14. blockExoticSubdeps 拦截 GitHub tarball 会导致 install_bundle 失败。

## 15. 同版本重打包不换已装文件会导致改动装不进去。

## 16. 递归删除 Windows junction 会跟随链接会导致误删源码。

## 17. 未停插件就卸载会导致数据被运行中的进程写回。

## 18. 渲染层 localStorage 不随卸载清除会导致重装后偏好仍在。

## 19. 使用不存在的 --st-raise 变量会导致选中色改了没反应。

## 20. 手工 insert 与 bundle selection 状态不同步会导致插件管理器显示错误。

## 21. 只重建 client.js 会漏掉独立生成物会导致样式/歌词仍旧。

## 22. fragment 顶层声明重名或重复扫描 .bundle.js 会导致重复声明报错。

## 23. 只改 folia-tailwind.css 而配套 .js 产物没变会导致样式仍旧。

## 24. 浏览器 IIFE 里用 Vite 的 import.meta.glob/相对资源会导致 404 或报错。

## 25. 只信 player snapshot 的暂停状态会导致背景继续动。

## 26. VisualizerShell 不转发 ref 会导致心象尺寸为 0。

## 27. 移除功能不做偏好迁移会导致老用户样式空白或回退错误。

## 28. 手改歌词/icu-folia 生成物会导致下次构建覆盖且难复现。

## 29. providerStore 固定平台列表再配双登录库会导致波点登录成功仍显示未登录。

## 30. 二维码没有取消与 TTL、状态不校验 key 会导致关窗后还能扫、一直转圈。

## 31. Folia Tailwind 与 i18n shim 未适配会导致字幕硬边方块与 ui.waitingForMusic。

## 32. DSH 从 profile 副本加载插件会导致重启后仍是旧构建。

## 33. 歌词加载器用裸 prefs 会导致全站歌词消失并抛 ReferenceError。

## 34. 缓存只挂在 ended 上会导致交叉淡化切走的歌永不缓存。

## 35. 波点成功态只认 success、取消不带 key 会导致扫码成功被判失败或新码被删。

## 36. 无条件调 forgetTokens 会导致退出登录时 Host 崩溃。

## 37. 删函数但轮询 effect 还在会导致面板每 3 秒报 ReferenceError。

## 38. 原生源 toTrack 不带 provider 会导致封面与取流变成 undefined。

## 39. 只认 singer 名或旧 card.cover 会导致歌手页/专辑卡缺图或缺 id。

## 40. 在线匹配写死 !onlineProvider 会导致在线歌曲点「在线匹配」无反应。

## 41. 头像/资料只读单一字段会导致登录后无头像或出现重复表单。

## 42. settings.js 引用 player-sheet 内部函数会导致切到歌词/数据页白屏。

## 43. 把 Audioid 当 albumAudioId 会导致酷狗点 A 播 B。

## 44. mute 用默认 ramp 重写 master gain 会导致 TTS 避让渐变被取消。

## 45. 概念版只发半套 metadata 会导致 high/lossless 取流 502。

## 46. 桥接层不补 buildTimedWords 会导致云阶/心象英文歌空白。

## 47. 新引擎不读回 prefs.volume 会导致重启音量回到 100%。

## 48. 把单页 limit 当总数会导致 QQ 歌单只显示 100 首。

## 49. 时钟用 DOM querySelector 找 audio 会导致淡化后歌词冻在首字。

## 50. 行索引用 4Hz timeupdate、词动画用 60Hz 会导致逐词错位。

## 51. override 只存 LRC 却保留 wordLevel 会导致面板说有词轴实际没有。

## 52. providers 把 local 当在线源且异步追加会导致重复「本地音乐」和列表不全。

## 53. 歌手行 truncate 无显式行高会导致莫奈歌手名上下被裁。

## 54. 自写样式顺序并漏掉行高会导致列表顺序与排版偏离 Folia。

## 55. grid stretch 加无 min-width 会导致账号卡被撑高、长 ID 溢出。

## 56. 缺旧版 getSongInfo 回退会导致酷狗个别老歌 404。

## 57. 字幕底距 shim 写死 64 会导致底部字幕比 Folia 低。

## 58. 能力表写 false 且未实现写接口会导致酷狗概念版/波点不能点赞。

## 60. 一次性自绘列表不走上层组件会导致加入歌单弹窗不像 DSH。

## 61. 来源页写死「本地」不按曲目分支会导致在线歌也显示本地与译文开关。

## 62. 改旧壳 PlayerPage 而不是 NowPlaying 会导致底栏改了没变化。

## 63. 只按单曲查 liked、不调 liked-ids 会导致红心一直不亮。

## 64. 只取歌单第一页会导致网易云等平台的歌曲数被单页上限截断。

## 65. 样式 seed 用 trackPath 而非 displaySong.id 会导致花火/绘光竖排。

## 66. 只抄常量、缺 profile 五级来源与 blend hold 会导致增益结果与 Folia 不同。

## 67. 平台增益只放响应头、不存缓存元数据会导致缓存重播丢失增益。

## 68. 把 profile 当字段对齐且无下一首预取/头部分析会导致平衡不准。

## 69. 缓存命中绕过平台增益头会导致重播 gain 变 null。

## 70. 对 Navidrome 下一首整曲下载做 profile 会导致浪费带宽。

## 71. profile 写入只重建四个字段会导致其余分析结果被丢掉。

## 72. 用 Blob Worker + IIFE bundle 却不保证独立加载会导致 Worker 起不来。

## 73. 把 gridFromBeats 当模型推理会导致没有 Beat This 时仍走频谱估算。

## 74. 存储 profile 不做版本校验会导致旧分析结果被当有效。

## 75. 消费端不读 profile 的拍点相位会导致过渡不卡拍。

## 76. 未缓存时 fetch 在线 stream 做分析会导致整首下载。

## 77. 把 keyRelation 当移调会导致和声被破坏的误解。

## 78. planner 的 hold/together 未被 transport 消费会导致听感仍是纯 crossfade。

## 79. profile 分析绑在 normalizeVolume 上会导致关平衡后失去 bpm/key。

## 80. 首音前等整首 blob 与分析会导致在线播放长时间加载。

## 81. 用 200 响应代替 206 会导致拖动进度回到开头。

## 82. 代理流的 seekability 不等价于 CDN 会导致 seek 重置。

## 83. 用 MSE 已 append 的 duration 当总长会导致进度条越拖越短。

## 84. 泛型 octet-stream 会导致 isTypeSupported 失败并静默回退。

## 85. profile 精确锁旧版本会导致启动时覆盖 install-local 的副本。

## 86. 在 play 事件就置 playing 会导致未出声却显示暂停图标。

## 87. 用普通 LRC 存逐字歌词会导致重播只剩逐行。

## 88. 直调酷狗包不补 userid/token/cookie 会导致云盘全空。

## 89. 单节点 CDN 403 且无多节点重试会导致海外网易云播不出。

## 90. 消费端只在 P3Shell 会导致面板折叠后 music_control 全部积压。

## 91. 字号/间距只写 CSS 钩子不接渲染器会导致设置拖动无变化。

## 92. 用归一化后的 source 判断平台歌词会导致择优开关永不生效。

## 93. i18n 同一键两处定义且只改一处会导致显示旧文案。

## 94. 设置应用点挂在会卸载的 UI 上会导致折叠后定时器/增益失效。

## 95. 按 Content-Type 而不是字节解封装会导致 FLAC 被当 MP3。

## 96. 清空只删持久层不清内存会导致播放后旧数据复活。

## 97. legacy 响度修正与 Folia 增益相乘会导致切模式声音反而变小。

## 98. 面板另走本地标签查询、不记在线增益会导致总显示没有标签。

## 99. 热替换只换 UI 不换播放器单例会导致增益显示未检测到。

## 100. 热替换后新旧 bundle 各持一套 prefsStore 会导致控件不动声音照变。

## 101. 取歌单前先全量 getMyPlaylists 且无超时会导致首次打开一直转圈。

## 102. 译文尺寸=歌词字号×翻译比例会导致两个滑杆被读成重复功能。

## 103. 页头按单行歌名固定高度会导致两行标题压住封面。

## 104. 卡片控件内联手绘且深色岛 token 不全会导致浅色主题露馅。

## 105. 深色岛未固定 switch 轨道/滑块 token 会导致开关全白难辨。

## 107. 卡片偏移只写 React state、不写 lyricOffsetMemory 会导致重开丢失。

## 108. dock 子项默认 min-height:0 且 overflow 隐藏会导致空会话歌词条被压扁。

## 109. MSE 无背压超 12MiB 配额会导致长音频停在 0:00。

## 110. 直连代理流写入 currentTime 被 Electron 丢弃会导致拖动回开头。

## 111. 滑杆组件定义在渲染函数内部会导致拖动一格就重挂。

## 112. 追加行高覆盖但虚拟步长不变会导致重启后列表字体变小、行距变空。

## 113. 字幕底距 shim 写死 0 会导致底部译文被胶囊压住。

## 114. 弹窗只认 provider prop 而右键只传 track 会导致永远说没有在线平台。

## 115. 弹窗正文无独立滚动容器会导致歌单多时被裁。

## 116. 拿 specialid 请求概念版 playlist_track_all 会导致 20010。

## 117. 把 tid 当 dirId 会导致 QQ 加入歌单失败或假成功。

## 118. 选择框不过滤平台可写目标会导致选出写不进去的歌单。
